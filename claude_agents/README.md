# Kollo Office (HA app)
Pixel-art AI office. Agents (Dev, Tess, Priya, Hal) run on ChatGPT, Gemini or Claude; Claude Code sessions appear via hooks.
1. Install the app, open Configuration, enter API keys (password fields), save, restart.
2. Open "Office" in the sidebar to assign tasks. The Lovelace card `custom:pixel-agents-card` shows the office.
3. Optional: merge hooks.json into ~/.claude/settings.json (replace HA_IP) to show Claude Code sessions.
